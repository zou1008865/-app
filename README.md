# 学生记账 App

一个面向大学生个人使用的人民币收支管理网页 App。

它可以帮助你记录收入和支出，查看本月收入、本月支出、本月结余，并按分类了解钱从哪里来、花到哪里去。

## 当前功能

- 记录收入和支出。
- 使用人民币金额展示。
- 金额输入最多两位小数，保存时按整数“分”处理。
- 新增记录时日期默认今天，可以手动修改。
- 使用侧边抽屉新增收支记录。
- 收支记录保存在浏览器 `localStorage` 中。
- 刷新页面后记录仍然保留。
- 可以删除单条收支记录。
- 首页显示本月收入、本月支出、本月结余。
- 收支明细页支持按月份、收入/支出和分类筛选。
- 分类统计页分别展示收入分类和支出分类。
- 点击分类可以进入分类详情页，查看该分类的全部记录。

## 固定分类

支出分类：

- 餐饮
- 交通
- 学习
- 购物
- 娱乐
- 生活
- 其他

收入分类：

- 生活费
- 兼职
- 奖学金
- 红包
- 退款
- 其他收入

## 当前不支持

- 账户、银行卡、钱包或初始余额管理。
- 转账。
- 预算。
- 登录。
- 云同步。
- 自定义分类。

这些能力以后如果要增加，需要先讨论方案再开发。

## 技术栈

- React：制作页面和交互。
- React Router：管理多个页面路由。
- TypeScript：减少字段写错和类型混乱。
- Vite：本地启动和正式构建。
- CSS：控制界面样式。
- localStorage：把记录保存在当前浏览器里。

## 页面路由

- `/`：财务概览。
- `/transactions`：收支明细。
- `/categories`：分类统计。
- `/categories/:type/:category`：分类详情。

## 启动项目

第一次运行前安装依赖：

```bash
npm install --cache .npm-cache
```

启动开发预览：

```bash
npm run dev
```

然后在浏览器打开终端显示的地址，通常是：

```text
http://127.0.0.1:5173/
```

如果 5173 被占用，Vite 会自动换成其他端口，按终端显示的地址打开即可。

## 检查项目

运行构建检查：

```bash
npm run build
```

这个命令会检查 TypeScript 代码，并生成正式网页文件到 `dist` 目录。

## 手动验收清单

- 可以新增一笔支出。
- 可以新增一笔收入。
- 收入分类和支出分类不会混用。
- 输入 `12` 可以保存为 `¥12.00`。
- 输入 `12.5` 可以保存为 `¥12.50`。
- 输入 `12.50` 可以保存为 `¥12.50`。
- 输入空金额、`0`、负数、文字或超过两位小数时不能保存。
- 修改日期后，记录列表显示选择的日期。
- 新增记录后刷新页面，记录仍然存在。
- 删除记录前会弹出确认。
- 删除记录后刷新页面，记录不会恢复。
- 首页本月收入、本月支出、本月结余会随记录变化。
- 结余可以是正数、0 或负数。
- 明细页按月份筛选结果正确。
- 明细页按收入/支出筛选结果正确。
- 明细页按分类筛选结果正确。
- 分类统计页金额和占比正确。
- 点击分类后，可以进入分类详情页。
- 分类详情页只显示对应类型和分类的记录。
- 没有记录时，页面显示空状态，不崩溃。

## 本地数据说明

数据保存在当前浏览器的 `localStorage` 中。

当前版本存储键为：

```text
student-finance-tracker:v2
```

旧版支出数据存储键为：

```text
student-expense-tracker:v1
```

如果浏览器里只有旧版 v1 数据，App 会尝试把旧支出记录迁移为新版 v2 收支记录，并保留旧数据。

如果清理浏览器数据，记账记录可能会丢失。当前版本暂不支持云同步。
