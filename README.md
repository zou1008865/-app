# 学生记账 App

一个面向大学生个人使用的人民币收支管理网页 App。

它可以帮助你记录收入和支出，查看本月收入、本月支出、本月结余，并按分类了解钱从哪里来、花到哪里去。

## 当前功能

- 记录收入和支出。
- 使用人民币金额展示。
- 金额输入最多两位小数，保存时按整数“分”处理。
- 新增记录时日期默认今天，可以手动修改。
- 使用侧边抽屉新增收支记录。
- 首页显示本月收入、本月支出、本月结余。
- 收支明细页支持按月份、收入/支出和分类筛选。
- 分类统计页分别展示收入分类和支出分类。
- 点击分类可以进入分类详情页，查看该分类的全部记录。
- 可以删除单条收支记录。
- 可以新增、改名和删除自定义分类。
- 删除自定义分类时，可以把历史记录迁移到其他分类。
- 数据保存到本机数据库，刷新页面后仍然保留。
- 兼容旧版浏览器 localStorage 数据，并在首次启动时尝试迁移。

## 固定分类

支出分类：

- 餐饮
- 交通
- 学习
- 购物
- 娱乐
- 生活
- 其他

收入分类：

- 生活费
- 兼职
- 奖学金
- 红包
- 退款
- 其他收入

固定分类由系统维护，不能改名或删除。自定义分类可以在“分类管理”页面维护。

## 当前不支持

- 账户、银行卡、钱包或初始余额管理。
- 转账。
- 预算。
- 登录和多用户。
- 云同步。
- 账本导入和导出。

这些能力以后如果要增加，需要先讨论方案再开发。

## 技术栈

- React：制作页面和交互。
- React Router：管理多个页面路由。
- TypeScript：减少字段写错和类型混乱。
- Vite：本地启动和正式构建。
- Express：提供本机数据接口。
- sql.js：把账本保存为项目目录中的 SQLite 数据库文件。
- CSS：控制界面样式。
- localStorage：兼容和读取旧版浏览器数据，作为迁移来源。

## 页面路由

- `/`：财务概览。
- `/transactions`：收支明细。
- `/categories`：分类统计。
- `/categories/:type/:category`：分类详情。
- `/category-manager`：分类管理。

## 数据保存方式

当前应用的主要数据文件是：

```text
data/finance.db
```

浏览器页面通过 API 访问这个本机数据库：

```text
浏览器 → React 前端 → Express API → sql.js → data/finance.db
```

项目第一次启动时，会尝试读取以下旧版浏览器数据：

```text
student-expense-tracker:v1
student-finance-tracker:v2
student-finance-tracker:custom-categories:v1
```

迁移成功后，旧的 localStorage 数据不会被删除。之后正常新增、删除记录和管理分类，主要通过本机 API 操作数据库。

如果清理浏览器数据，已经迁移到 `data/finance.db` 的记录不会因此消失；如果删除数据库文件，则本机账本数据会丢失。

## 启动项目

第一次运行前安装依赖：

```bash
npm install --cache .npm-cache
```

启动开发环境：

```bash
npm run dev
```

这个命令会同时启动：

- Vite 前端：`http://127.0.0.1:5173/`
- Express API：`http://127.0.0.1:5174/`

然后在浏览器打开：

```text
http://127.0.0.1:5173/
```

如果 5173 或 5174 被占用，程序可能无法按默认配置启动，需要先关闭占用端口的程序。

## 检查项目

运行构建检查：

```bash
npm run build
```

这个命令会检查 TypeScript 代码，并生成正式网页文件到 `dist` 目录。它不会启动 Express API。

当前项目还没有自动化业务测试，主要通过构建检查和浏览器手动验收验证。

## 手动验收清单

- 可以打开财务概览、收支明细、分类统计和分类管理页面。
- 可以新增一笔支出。
- 可以新增一笔收入。
- 收入分类和支出分类不会混用。
- 可以新增自定义分类。
- 固定分类不能改名或删除。
- 自定义分类可以改名。
- 删除自定义分类前会要求选择替代分类。
- 输入 `12` 可以保存为 `¥12.00`。
- 输入 `12.5` 可以保存为 `¥12.50`。
- 输入 `12.50` 可以保存为 `¥12.50`。
- 输入空金额、`0`、负数、文字或超过两位小数时不能保存。
- 修改日期后，记录列表显示选择的日期。
- 新增记录后刷新页面，记录仍然存在。
- 删除记录前会弹出确认。
- 删除记录后刷新页面，记录不会恢复。
- 首页本月收入、本月支出、本月结余会随记录变化。
- 结余可以是正数、0 或负数。
- 明细页按月份筛选结果正确。
- 明细页按收入/支出筛选结果正确。
- 明细页按分类筛选结果正确。
- 分类统计页金额和占比正确。
- 点击分类后，可以进入分类详情页。
- 分类详情页只显示对应类型和分类的记录。
- 没有记录时，页面显示空状态，不崩溃。
- 关闭 API 服务时，页面显示清楚的错误提示，而不是直接崩溃。

## 学习提示

推荐按照下面的顺序阅读代码：

1. `src/main.tsx`：前端入口和路由容器。
2. `src/App.tsx`：全局导航和旧数据迁移入口。
3. `src/pages/OverviewPage.tsx`：首页、表单和新增/删除交互。
4. `src/pages/TransactionsPage.tsx`：筛选和明细列表。
5. `src/stats.ts`：统计计算规则。
6. `src/api.ts`：前端如何请求后端接口。
7. `server/index.ts`：API 和本机数据库如何保存数据。

## 开发约定

- 一次只开发一个小阶段。
- 修改前先阅读 `CODEX.md` 和相关代码。
- 新增依赖前先说明用途和必要性。
- 每次修改后运行相关检查或构建命令。
- 不擅自加入登录、云同步、账户体系等大功能。
- 涉及数据存储或架构的重大变化时，先讨论方案。
